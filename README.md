Full-stack web application built with FastAPI and Vue.js, designed to make image classification model training accessible to professionals from a wide range of non-computing fields. It includes everything from creating and maintaining image datasets (as well as sharing them with other users) to training, evaluating, and running inference with models using different neural network architectures. 
This was my final Bachelor's final project and received a grade of 10/10 with highest honors.
o Keras for the machine learning component.
o User authentication implemented from scratch with JWT, including email verification and password recovery.
o Model training managed through a queue system using Celery and RabbitMQ.
o NGINX as a reverse proxy.
o PostgreSQL as the database and SQLModel as the ORM.
o Docker Compose for quick and easy deployment.
o Deployed on a DigitalOcean VPS.
